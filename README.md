# fmm_add_reduction
A Python repository for minimizing the number of additions in fast matrix multiplication algorithms.

This repo corresponds to the paper "The Number of the Beast: Reducing Additions in Fast Matrix Multiplication Algorithms for Dimensions up to 666", available on ePrint at https://eprint.iacr.org/2024/2063.

The code consists of a single Python file and uses numpy a bit. 

Our C implementation for the same thing is available at https://github.com/werekorren/fmm_add_reduction.
